# StudyTime

## Project Overview

StudyTime is a responsive study timer application designed for
college students who want to stay focused while studying,
completing assignments, or preparing for exams.

The application allows users to enter a study subject, select
a session duration, control a countdown timer, and track their
completed study sessions through a saved study history.

## Planned Features

- F1: Set up a study session.
- F2: Control the study timer.
- F3: Review and manage study history.
- Responsive layouts for narrow and wide screens.
- Local Storage for completed sessions and duration preferences.
